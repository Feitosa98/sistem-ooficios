Assine com seu certificado, sem sair do sistema

Instale o componente local e a extensão no Windows, com Chrome ou Edge. A assinatura começa no site e é confirmada em uma janela do Windows.

Baixar assinador para Windows

Prepare seu certificado

A1: importe o arquivo .pfx ou .p12 no Windows em Usuário Atual → Pessoal. A3: conecte o token ou cartão e instale o driver oficial. O certificado deve estar disponível no repositório pessoal do Windows.

Instalação rápida (3 passos simples)

  1. Extraia o arquivo ZIP baixado para uma pasta permanente no seu computador (ex.: em Documentos).
  2. Dê um duplo clique no arquivo instalar.bat para registrar o assinador automaticamente no Windows (não precisa abrir PowerShell nem digitar códigos).
  3. Abra chrome://extensions no Chrome (ou edge://extensions no Edge), ative o Modo do desenvolvedor no canto superior, clique em Carregar sem compactação e escolha a pasta extension que foi extraída.
  4. Pronto! Recarregue a página do sistema, abra a assinatura e escolha Assinador local — Windows, A1 e A3.
Compatibilidade: Windows 10/11 com .NET Framework 4.8 e certificados RSA. Tokens A3 precisam de driver compatível com o repositório de certificados do Windows; a compatibilidade deve ser testada com seu dispositivo. Esta versão usa instalação manual da extensão e não possui assinatura Authenticode do executável.

A chave privada permanece no computador ou token. O sistema continua verificando a assinatura e a confiança do certificado antes de salvar o PDF.
